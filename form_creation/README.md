# Form Creation

### `create_form.py`
Automatically generates Google Forms to collect human evaluations on the forensic scenarios. The script reads the CSV dataset, extracts the events, and creates a structured questionnaire asking users to evaluate logical coherence and either approve or reject the inferences.
- **Features:**
  - Configurable random sampling (with `seed` for reproducibility).
  - Optional automatic translation from English to Italian using `argostranslate`.
  - Automatic saving of form metadata, including sharing and editing links.
- **API Requirement (Important):** The script requires a credentials file (`client_secrets.json`) to authenticate with the Google Forms and Google Drive APIs. This file must be generated from your Google Cloud Console. For obvious security reasons, it is **not included** in the repository, but its presence in the working directory is mandatory for the script to function.
- **Usage:**
    ```bash
    python tools/create_form.py --csv ../data/filtered_atomic_v2.csv --random-sample --sample-size 50 --seed 14
    ```

### `event_validation.ipynb`
A Jupyter Notebook dedicated to the comparative analysis between human judgments (collected via Google Forms) and the automated evaluations generated by the LLM (Multi-Judge Tribunal).
- **Processing:** Parses the CSVs containing human responses, calculates mean scores, and deterministically merges them with the original LLM log using bridge columns (event, xIntent, xEffect).
- **Statistical Metrics:** Calculates decision agreement rates, Mean Absolute Error (MAE) on scores, and statistical correlations (Pearson r and Spearman rho) between humans and the AI.
- **Visual Dashboard:** Automatically generates visual reports ready for a thesis/paper (`thesis_validation_dashboard.png`), including pie charts (agreement), bar charts (approval rates), density plots, and correlation scatter plots, along with the final confusion matrix.
- **Output:** Exports the merged dataset to `global_comparison_results.csv` and a statistical summary to `global_statistics_summary.json`.
